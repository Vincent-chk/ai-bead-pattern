# AI 拼豆图纸实施计划

> 分阶段执行；项目规格以根目录 `SPEC.md` 为准。测试优先验证用户行为，避免为未来扩展增添不必要抽象。

**目标：** 基于合规开源底座完成本地拼豆工具、真实生图服务接入、Apple 芯片 macOS 下载包及公开发布。

**约束：** 29/52/104 方形裁切；按原始像素面积及 alpha 求均值、50% 透明留空、MARD 色号；不自动去白、限色或逐格编辑；PNG 含逐格色号与统计。布局精简；上传转换离线；自带用户自己的 Key；普通用户无需安装运行时。

**任务依赖：** 上游和许可基线 → 转换核心、模型服务、页面流程可并行 → 整合与端到端 → macOS 包和真实模型验证 → 审核、GitHub 发布。

## 一、转换核心

- [ ] 在现有核心边界新增面积和 alpha 加权精确裁切转换，确定色号映射，支持透明格和统计。
- [ ] 先用可手算样例编写失败测试并运行，再实现；覆盖白底、50% 边界、非整除分格、三个尺寸和不自动合并颜色。
- [ ] 运行核心测试，保留上游色卡许可证与声明。

## 二、生图与本机服务

- [ ] 在本机服务实现 Seedream 与 OpenAI 图片接口，支持用户提供地址、模型和本机安全 Key 保存、删除；参考图必须走真正编辑接口。
- [ ] 测试结果解析、部分失败、无效凭证、请求跨源限制和参考图上传，优先测试公开行为；真实调用单独记录。
- [ ] 图纸本地处理，只有用户主动生图时联网；不泄露 Key。

## 三、用户界面

- [ ] 在现有本地界面基础上实现简洁中文流程：输入、尺寸、色卡、三张候选或上传、方形裁切、图纸与 PNG。
- [ ] 不增加次级说明，隐藏无关编辑和转换参数；结果含色号、数量、缩放和高分辨率导出。
- [ ] 以浏览器测试上传至导出的完整流程；确保界面与导出数据一致。

## 四、整合、交付与验收

- [ ] 顺序合并独立任务，解决接口差异，执行单元、接口、浏览器与离线测试；修复发现的问题。
- [ ] 构建自包含 Apple Silicon macOS 启动包，下载后无需自行安装 Node/Python；验证本地启动与关闭，标明签名、公证与真实测试限制。
- [ ] 真实运行 Seedream 生图与参考图修改，记录截图和失败边界；没有凭证时不得虚构验证结果。
- [ ] 独立代码审查，检查许可及密钥；更新中文说明，在 GitHub 公开仓库和 Release 发布实际验证成果。

## 重点风险

- 图片非整除裁切边界、半透明覆盖率恰好 50%、白豆与空格区分。
- 模型返回图片数量不足、临时 URL 失效、生成成功但编辑不支持。
- 本地敏感 API 被其他网页跨站调用或意外泄露 Key。
- 104×104 图片导出格号或统计清单被裁切、过小。
- macOS 运行时依赖本机 Homebrew、系统阻止未签名程序或关闭后进程未退出。
